git status: Te dice cómo está tu repositorio y qué archivos tienen cambios.
git add: Prepara los archivos que quieres guardar en el siguiente commit.
git commit: Guarda los cambios que hiciste y les pone un mensaje para saber qué cambiaste.
git push: Sube tus cambios a GitHub.
git pull: Baja los cambios más nuevos que están en GitHub.
git log: Te enseña el historial de commits que se han hecho.
git diff: Muestra qué cambios hiciste en los archivos.
git restore: Sirve para quitar cambios que hiciste en un archivo y regresarlo como estaba antes
git restore --staged: Quita un archivo de los que ya habías preparado con git add, pero no borra los cambios que hiciste.
